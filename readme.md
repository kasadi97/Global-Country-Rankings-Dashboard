 🌍 World Country Rankings Dashboard

## 📌 Описание проекта
Интерактивный Power BI-дешборд, позволяющий анализировать рейтинги стран по разным показателям (коррупция, демократия и др.). Проект показывает топ-5 стран по выбранному индикатору, средние значения и визуализацию на карте.

## 🧰 Использованные инструменты
- Power BI (визуализации, карты, KPI, срезы)
- Power Query (Unpivot таблицы)
- CSV-файл с рейтингами стран

## 📊 Что показывает дашборд
- Срез по рейтингу
- Топ-5 стран по выбранному показателю
- Худшая страна по имеющимся данным (Last Rank)
- Географическая карта с визуализацией рангов

## 🧠 Цель проекта
Показать навыки обработки данных, построения интерактивных визуализаций и работы с аналитическими дашбордами.
